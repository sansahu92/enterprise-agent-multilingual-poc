# Application Access Request Procedure

## 1. Requesting access
Access to business applications such as SAP S/4HANA or Dynamics 365 Finance is requested through the ServiceNow service catalog. Each request must state the application, the role required, the start date and a business justification.

## 2. Approval
Access requests are approved by the employee's line manager and the application owner in ServiceNow before provisioning.
